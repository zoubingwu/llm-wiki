# Pi

Pi 是 [[What is a Harness]] 中用来说明 agent harness 的案例：一个面向终端的本地 agent harness，提供简短的 system prompt、较小的工具集和可扩展的 extension 机制。

文章将 Pi 与普通 AI 应用区分开来：用户可以在自己的设备上运行和改造 harness，切换模型，保存会话，并通过 extension 让工具适应个人工作流。文中还将 Pi 描述为免费、开源、追求模型中立的 harness；这些描述属于该来源文章的产品定位，不是本页对所有版本行为的独立审计。
