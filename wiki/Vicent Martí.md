# Vicent Martí

Vicent Martí 是 Cursor 官方博客文章 [[Git at any scale]] 的作者，也是文中 [[Continuity (Cnt)]] 与 [[Origin]] Git 基础设施工作的参与者。文章以 GitHub 早期存储演进、[[Spokes]] 的长期实践和 Cursor 的新设计为主线，讨论大规模 [[Git Repository Hosting|Git 存储库托管]]的性能、一致性与运维取舍。
